## How the paper's objects are modelled

The model is inherited from `Subspace.lean`:

- `F` is `FMod K r n`, the coefficient functions on `Mon r n = Fin r × Finset (Fin n)`.
- `F_j` is `Fdeg K n d j`.
- `e_x` is `ex x`, and `E₁V` is `E1 V`.
- `K` is any field.
- The generator degrees `d : Fin r → ℤ` are assumed `Monotone`, the paper's standing
  `d₁ ≤ ⋯ ≤ d_r`.

Added in `Main.lean`:

- `IsESub M := ∀ x, ∀ v ∈ M, ex x v ∈ M`: `M` is an E-submodule, that is, a `K`-subspace closed
  under every `e_x`. Since `E` is generated by the `e_x`, this is closure under `E`.
- `gproj d j v`: `v` restricted to the monomials `e_σ gᵢ` of degree `dᵢ + #σ = j`.
- `IsGradedF d M := ∀ v ∈ M, ∀ j, gproj d j v ∈ M`: `M` is graded, that is, `M = ⊕ⱼ M ∩ F_j`.
- `hilbQ d M j = dim F_j − dim (M ∩ F_j)`, from `Subspace.lean`. For a graded `M` this is
  `H_{F/M}(j)`.
- `IsLexFSegF n d j L`: the paper's definition of a lexF segment, read literally. It says
  `L ⊆ Mon_j(F)` (that is, `monDeg n d j`), and that `m ∈ L`, `m' ∈ Mon_j(F)` and `m' >_lexF m`
  (`LexFGT m' m`) together imply `m' ∈ L`.
- `Egen S := sInf {N | S ⊆ N ∧ IsESub N}`: the E-submodule generated by `S`.
- `monoVecs K L`: the basis vectors `e_σ gᵢ`, `(i,σ) ∈ L`, as a set of vectors.
- `IsLexSet n d 𝓛 := Shad 𝓛 ⊆ 𝓛 ∧ ∀ j, IsLexFSegF n d j (𝓛 ∩ monDeg n d j)`. With it,
  `monoSpan K 𝓛` is a lex submodule: a monomial E-submodule all of whose graded pieces are lexF
  segments. Two lemmas tie it to the paper's notions:
  - `isESub_monoSpan_iff : IsESub (monoSpan K 𝒜) ↔ Shad 𝒜 ⊆ 𝒜`
  - `isGradedF_monoSpan`: monomial subspaces are graded.

### What the equality clause says, exactly

Take any E-submodule `M` of `F`, graded or not, and any `j ∈ ℤ`. Let `L` be the lexF segment of
`Mon_j(F)` with `|L| = dim M_j = dim (M ∩ F_j)`; it exists and is unique. Let `N` be the
E-submodule generated by the monomials of `L`, that is, the smallest `K`-subspace containing them
and closed under every `e_x`. Then:

- `N` is an E-submodule, and it is graded.
- `H_{F/N}(j) = H_{F/M}(j)`. Both equal `dim F_j − |L|`.
- `H_{F/N}(j+1) = B(H_{F/M}(j), j)`, which is `B(H_{F/N}(j), j)`. So `N` attains the bound of
  `cor-prop41` in degree `j+1`.

**The identification of `N`.** It is not left implicit. It is proved as

```lean
theorem Egen_monoVecs (𝒜 : Finset (Mon r n)) : Egen (monoVecs K 𝒜) = monoSpan K (upClos 𝒜)
```

Here `upClos 𝒜` is the set of monomials `e_τ gᵢ` with `e_σ gᵢ ∈ 𝒜` and `σ ⊆ τ`. The two graded
pieces that matter are then computed:

- `upClos L ∩ Mon_j(F) = L` (`upClos_inter_monDeg`);
- `upClos L ∩ Mon_{j+1}(F) = Shad L` (`upClos_inter_monDeg_succ`).

The formula half of `thm_module_kk` finishes the proof.

**The paper's "graded".** The inequality is proved for every E-stable subspace, with no gradedness
hypothesis. The paper's graded submodules are a special case. This is a strengthening.
`cor_prop41_family_B` is the version for graded families `M_j ⊆ F_j` with `E₁M_j ⊆ M_{j+1}`.

### What the formal (1) says, exactly

Fix any field `K`. Condition (1) asks for a `K`-subspace `M` of the model `F = FMod K r n` with
three properties:

- `M` is closed under every `e_x`, so it is an E-submodule.
- `M` is closed under taking homogeneous components (`gproj`), so `M = ⊕ⱼ (M ∩ F_j)`.
- `dim F_j − dim (M ∩ F_j) = h_j` for every `j ∈ ℤ`.

That is, `h = H_{F/M}` for a graded submodule `M ⊆ F`. The window is the paper's: `d₁ = d 0` and
`d_r = d (r−1)`, and `h` vanishes outside `[d₁, d_r + n]`.

Condition (2) is the paper's, with the printed `B`, for `j ∈ [d₁ − 1, d_r + n − 1]`.

Condition (3) asks for a lex submodule `monoSpan K 𝓛` with quotient Hilbert function `h`. For
uniqueness there are two forms:

- `thm_ac42_lex_unique`: two lex submodules with equal quotient Hilbert functions have equal
  monomial sets, so the subspaces are equal too;
- `thm_ac42_existsUnique`: under (2) the lex submodule exists and is unique.

### Observations

1. **`Bω = B` everywhere, not only on `0 ≤ h ≤ dim F_j`.** Outside the domain both are
   `dim F_{j+1}`, since ℓ = 0. So the shadow-form and printed forms of `def-B` are the same total
   function. See `Bω_eq_growthB_macaulayUp`.
2. **`cor-prop41` does not need gradedness.** The inequality holds for every E-stable subspace,
   with `H(j) := dim F_j − dim (M ∩ F_j)`. The `Subspace.lean` agent noted this already.
   Consequently `thm-ac42` (1) may be relaxed to "some E-submodule, graded or not" without changing
   the set of `h`; see `thm_ac42_ungraded`. Every such `h` is already the Hilbert function of a
   graded, indeed lex, submodule.
3. **How the equality clause of `cor-prop41` must be read.** The sentence "with equality for the
   submodule generated by the lexF segment of size `dim M_j`" is correct. It is about the
   submodule `N`, not about `M`. `N` agrees with `M` only in degree `j`: there `H_{F/N}(j) =
   H_{F/M}(j)`, and `N` vanishes below `j`. `N` then has `H_{F/N}(j+1) = B(H_{F/N}(j), j)`. This is
   what is proved. If the sentence is ever expanded, saying "N, which has `H_{F/N}(j) =
   H_{F/M}(j)`" would remove any chance of reading "equality" as a claim about `M`. This is not an
   error.
4. **`thm-ac42` implicitly needs `r ≥ 1`.** Otherwise `d₁` and `d_r` are undefined. The Lean
   statement takes `hr : 0 < r` and writes the window as `d ⟨0,hr⟩`, `d ⟨r−1,_⟩`. This is not a
   defect, since the paper's `F` has generators. As `LexF.lean` already observed, (2) ⇒ (3) holds
   for any window `[d₁, d_r]` containing the support of `h`. `thm_ac42_two_three_F` and
   `thm_ac42_existsUnique` are stated that way, with arbitrary `d₁`, `dr`.
5. **`cor-initial` holds for every `j₀ ∈ ℤ`.** This was inherited from `LexF.lean`. The initial
   degree matters only in `cor_initial_instances_B`.
6. **Model caveat, inherited from `Subspace.lean`.** `F` is modelled by its monomial basis with
   explicit operators `ex x`, which are checked to satisfy `e_x² = 0` and
   `e_x e_y = −e_y e_x`. It is not identified with Mathlib's `ExteriorAlgebra`. "E-submodule"
   means "closed under every `e_x`", and "graded" means "closed under homogeneous components".
