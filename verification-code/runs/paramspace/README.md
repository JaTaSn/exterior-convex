# runs/paramspace/ — parameter-space experiments, n = 4 and 5, d = 1

JSON output of the experiments of 2026-07-31 and 2026-08-01 on how the face structure of
rasimp(a) + shift(rasimp(a)) depends on the leg vector a: grid, random and mesh samples for
n = 4, and seeded samples run in both Sage and Julia for n = 5. Produced by
`code/oneoff/parameter_space_n4d1*.py`, `parameter_space_n5d1*.py` and `parameter_space_n5d1.jl`,
compared by `code/oneoff/compare_n5d1_tandem.py`. Account: `LOGBOOK/LOGBOOK-session-03-20260731.md`
and `LOGBOOK/LOGBOOK-session-04-20260801.md`. Moved here from `runs/` on 2026-11-08.
